# Hearthwillow {{VERSION}}

A quiet village for wandering, animals, gardening, cooking, tea, writing and
focusing. This is an early single-player, offline game; no Godot installation or
account is needed.

- [Download for Mac — Apple Silicon and Intel](https://github.com/{{REPOSITORY}}/releases/download/{{TAG}}/Hearthwillow-macOS-universal.zip)
- [Download for Windows x64 — Intel and AMD](https://github.com/{{REPOSITORY}}/releases/download/{{TAG}}/Hearthwillow-Windows-x64.zip)

**Mac:** unzip, drag Hearthwillow.app into Applications, and open it. The app uses
free ad-hoc signing and is not notarized. If blocked, try opening once, then use
System Settings → Privacy & Security → Open Anyway.

**Windows:** extract the entire ZIP and open Hearthwillow.exe. Keep the accompanying
files together. The app is unsigned; SmartScreen may offer More info → Run anyway.
Smart App Control or managed security policies may block unsigned apps.

WASD/arrows move, mouse looks, Escape releases the mouse, E/F perform nearby
actions, M opens the map, comma opens Settings, and O turns sound on. Saves stay
on your computer; browser multiplayer and browser saves are separate.

Both downloads passed archive, checksum and packed-resource checks. The universal
Mac signature and headless startup, plus native Windows headless startup, passed.
These automated checks do not verify graphics, gameplay, audio, Gatekeeper
download acceptance or performance. No particular frame rate is promised.

Third-party notices are included in both ZIPs. SHA256SUMS.txt contains the ZIP
checksums. Source commit: [{{COMMIT}}](https://github.com/{{REPOSITORY}}/commit/{{COMMIT}}).
